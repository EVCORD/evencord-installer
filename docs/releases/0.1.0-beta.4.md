# EvenCord Installer 0.1.0-beta.4

The installer now shows a channel selector for Discord Stable, PTB and Canary, with detection status and the selected installation path. Refresh scans the standard Windows installation folders. The window has additional vertical space for the selector and controls.

Only Stable installation is currently authorized by the signed core and loader protocol. PTB and Canary can be inspected, but installation, repair, recovery and removal on those channels remain disabled. They require verified channel compatibility before support can be enabled. Selecting a channel does not modify it.

The supported Stable installation still uses signed metadata, archive compatibility, ownership checks, integrity verification and recovery. This installer retrieves the latest approved core release independently of its own version. Core beta.5 remains the current client release. Windows executables are not Authenticode signed.
