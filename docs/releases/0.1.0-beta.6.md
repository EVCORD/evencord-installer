# EvenCord Installer 0.1.0-beta.6

Restores the upstream Equilotl close-before-patching flow. Install, repair, recovery and uninstall close the selected Discord channel automatically and wait for its processes to exit before changing files. Process executable paths are matched to the selected installation, so other channels stay open. Save unsaved clips or work before starting an operation. If Windows denies closing the selected process, quit that channel manually and retry.

Fresh installations also check whether Windows allows the original app.asar to be renamed before activating a payload or writing a loader transaction. A locked archive gives a clear instruction instead of a raw rename-path error. A process can still start between checking and replacement; existing ownership and recovery safeguards remain active.

If an older installer already failed with a file-in-use error and shows Recovery available, close that Discord channel, choose Recover, then Install. Do not delete app.asar, _app.asar or recovery records manually. Settings and account data are preserved.

Stable, PTB and Canary support and channel isolation are unchanged. Core beta.6 remains the latest signed client payload. Windows executables are not Authenticode signed.

The installer content scrolls on smaller windows so operation controls and guidance remain reachable.
