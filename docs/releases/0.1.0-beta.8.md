# EvenCord Installer 0.1.0-beta.8

Fixes an installation blocker when Windows denies access to a running Discord process, including protected Canary subprocesses.

The installer now inspects processes with query-only access before requesting permission to close a process inside the selected installation. It rechecks the executable path on the termination handle and never closes an unverified process. Inaccessible or already exited processes no longer abort the operation; the installation engine still checks archive locks and preserves ownership and recovery safeguards.

Download this installer again, select the affected Discord channel, and retry Install or Repair. If a real archive lock remains, save your work and fully quit that channel from its tray icon before retrying. Use Recover first if an earlier interrupted operation offers it.

This installer retrieves the latest verified EvenCord beta core, currently 0.1.0-beta.8. Existing settings and recovery archives are preserved. Windows executables are not Authenticode signed; release metadata is authenticated with the pinned Ed25519 key, with artifact size and SHA-256 verification.

Validation: focused process-permission regression cases, the locked-original archive regression, and Windows GUI/CLI builds. No real Discord installation was modified or restarted during development. Runtime confirmation on the affected tester's PC remains necessary.
