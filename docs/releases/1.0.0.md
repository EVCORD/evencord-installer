# EvenCord Installer 1.0.0

Windows x64 installer for EvenCord stable releases on reviewed Discord Stable, PTB and Canary archives.

The installer retrieves EvenCord's own stable release channel, verifies pinned Ed25519 release signatures and artifact size/SHA-256, then applies ownership, compatibility and recovery checks before installation. No Equicord binary fallback is used.

Existing public beta installations can be upgraded without deleting settings or the original Discord archive. The signing key is unchanged; the loader channel policy is migrated using resumable ownership records. Update-enabled beta clients also receive an automatic transition update before the stable release, so downloading this installer is optional for those clients.

Process inspection uses limited permissions. Protected or already exited subprocesses do not cause a false installation blocker; real locked archives still prevent unsafe replacement. Save work before applying an operation because the selected Discord installation is closed where permitted. Other channels are not closed.

Install, Repair, Recover and Uninstall retain their existing safeguards. Unknown modifications and unapproved Discord archives are rejected. Settings are preserved on uninstall. Windows executables are not Authenticode signed; installer self-update remains unavailable. No real Discord installation was changed during development validation.
