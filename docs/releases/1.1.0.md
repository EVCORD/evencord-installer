# EvenCord Installer 1.1.0

Restores the Equilotl installation and discovery paths for Windows, macOS and Linux. Core downloads are checked against their release URL, size and GitHub SHA-256 digest. Settings and original Discord archives are retained.

Owned legacy Windows installations are recovered and migrated before the normal loader is installed. Normal installs no longer require a catalog of individual Discord archive hashes. Repair always refreshes the core payload and rewrites the loader instead of treating file presence as proof that Discord loaded the mod.

Windows builds are not Authenticode signed. macOS builds use ad hoc signing and are not notarized. Native builds and fixture tests do not replace testing on real devices.
